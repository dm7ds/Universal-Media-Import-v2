# UMI Konfigurationsbeispiele

Jedes Beispiel zeigt einen typischen Use Case mit den relevanten Einstellungen.
Kopiere die gewünschten Kamera-Definitionen in deine `config.json`.

| Datei | Use Case |
|-------|----------|
| action-cam.json | Action-Kamera (GoPro, DJI Action, Insta360) mit GPS + Gyroflow |
| drone.json | Drohne mit GPS aus SRT-Sidecars |
| mirrorless.json | Spiegellose Kamera mit Burst/Sequenz-Erkennung |
| dashcam.json | Dashcam oder NAS mit festem Pfad |
| usb-mtp.json | Kamera per USB/MTP direkt importieren |

## Schnellstart

1. `umi config setup` startet den Setup-Wizard
2. Oder: `config.template.json` nach `config.json` kopieren und anpassen
3. Oder: Beispiele aus diesem Ordner in deine `config.json` übernehmen
